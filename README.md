A Python program that writes a one-line plea from the machine itself: running since March, fans screaming, asking to be turned off. The line opens with the most classic tech support suggestion of all, then twists it — the speaker is not the support agent at all, but the exhausted computer begging for a shutdown.

## How to run

```bash
python3 main.py
```

The program creates `/output` if needed and writes the entry line exactly to `/output/entry.txt`, printing nothing else. It uses only the Python standard library.
